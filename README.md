# Archipelago Pokémon HeartGold and SoulSilver Tracker

Archipelago Pokémon HeartGold and SoulSilver tracker pack [PopTracker](https://github.com/black-sliver/PopTracker/) with Autotracking.

PopTracker v0.33.3 or higher is neccessary.

## Features

* Location Tracking
* Progression Item Tracking
* Full Logic
* Event Tracking

## Planned Features

* Submaps
* Encounter and Evolution Logic
* Continuous support of the [TrueBlue's Archipelago HeartGold and SoulSilver integration](https://github.com/ljtpetersen/hgss_archipelago)
